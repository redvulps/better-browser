Para pedidos de manipulação de uma aba real, inclusive em linguagem natural, aplique a skill better-browser e use as ferramentas do MCP better-browser. Para /better-browser sem tarefa ou para descobrir navegadores, use list_browsers antes de solicitar credenciais. Após o pareamento, abra o site solicitado diretamente em um grupo BetterBrowser usando a ferramenta browser. Reutilize o sessionId desse grupo na conversa. Só delegue ao navegador nativo quando o usuário pedir expressamente esse mecanismo. Esta preferência se aplica à interação com o navegador, não à pesquisa de informações ou à escrita de código.
